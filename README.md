## About me

I'm a 2nd-year CS student who genuinely enjoys building things that real people end up using. Not everything I've made has been perfect, but it shipped, it worked, and I can explain every decision I made along the way. Right now I'm focused on getting better at the fundamentals: system design, databases, distributed systems, and writing code I'd be proud to have someone else read.

- Built a production event management system for NMDC Limited (India's largest iron-ore PSU) - solo, 5 weeks, from architecture to IIS deployment. The old process was Excel sheets and manual follow-ups.
- Created an ML engine that rates football players using 6 composite metrics instead of just goals and assists. Used K-Means clustering to group player archetypes: I chose that over DBSCAN because outliers felt like important signals, not noise.
- Built a Chrome extension that corrects colors in real time for people with color vision deficiency, using hardware-accelerated SVG filters. Top 5 at a hackathon.
- Made a simple fare comparison app for Uber, Ola, and Rapido because checking three apps in Chennai traffic is a headache.

## Some projects

| Project | What it is | Stack |
|---|---|---|
| NMDC Event Management System | Internal platform for a government PSU, replacing manual workflows. Role-based auth, audit trails, real-time updates via SignalR, PDF reports. Built and deployed solo in 5 weeks. | ASP.NET Core, SQL Server, SignalR, IIS |
| Football Player Impact Rating | ML scoring model using 6 composite metrics (PPI, DAQ, CCC, etc.) with position-specific normalisation and K-Means clustering for archetype classification. | Python, Scikit-learn, Pandas |
| Pet Adoption & Care System | Full-stack shelter management app with a heavily normalised MySQL schema (BCNF/4NF/5NF), triggers, views, stored procedures, 4-tier RBAC, REST API. | Next.js, TypeScript, MySQL, Recharts |
| OpenIris | Real-time color correction extension for CVD using SVG feColorMatrix injection. Manifest V3, covers all major CVD types. | JavaScript, Chrome APIs |
| MeterDown | Fare aggregator comparing Uber, Ola, Rapido in Chennai. SHA-256 auth, admin analytics, Tamil language support, full MVC. | Java, Swing, SQLite |
