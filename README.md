## About me

> I'm a 2nd-year CS student who builds things for real — deployed to production, used by actual humans, with actual stakes. Not everything I've built has been pretty. Some of it was genuinely chaotic. But it shipped, and it worked, and I can defend every decision cold.
>
> Currently on a mission to go from *"I vibe-coded this"* to *"I architected this."* Progress: ongoing.

- 🏭 Built a **production Event Management System** for NMDC Limited (India's largest iron-ore PSU) — solo, in 5 weeks, from architecture to IIS deployment. The legacy system was Excel sheets. No pressure.
- ⚽ Wrote an ML engine that rates football players using 6 composite metrics because goals + assists is statistically insulting to centre-backs everywhere. K-Means over DBSCAN — outliers are signal, not noise.
- 🎨 Built a Chrome extension that corrects colors for 300 million people with color vision deficiency. Hardware-accelerated, zero-lag. Top 5 at hackathon.
- 🚕 Made an app that compares Uber, Ola and Rapido fares in one place, because Chennai traffic is already stressful enough.
